# Zomato Restaurant Data Analysis

## Project Overview
Exploratory Data Analysis (EDA) of Zomato restaurant data
using Python to understand restaurant trends, customer ratings,
online ordering, pricing, and customer engagement.

## Objectives
- Analyze different restaurant categories.
- Explore restaurant rating distributions.
- Compare ratings for online and offline ordering.
- Analyze approximate dining costs for two people.
- Compare customer votes across restaurant categories.

## Technologies Used
- Python
- Pandas
- Matplotlib
- Seaborn
- Jupyter Notebook

## Key Insights
- Dining restaurants received the highest total votes
  among the restaurant categories in the dataset.
- Restaurants offering online ordering showed higher
  ratings in the analyzed data.
- Most restaurant ratings were concentrated around 3.5–4.2.

## Project Files
- `Zomato_project.ipynb`: Analysis and visualizations.
- `Zomato data .csv`: Dataset used in the project.

## Skills Demonstrated
Data Cleaning, Exploratory Data Analysis,
Data Visualization, Python, and Statistical Analysis.
